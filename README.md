# Group 18: Diffusion_Models_for_Image_Inpainting
In the python notebook ```DL_group_18_custom_unet_architecture.ipynb``` the implementation with our custom U-Net architecture can be found and in the python notebook ```DL_group_18_unet_architecture_from_ku.ipynb``` the implementation with the U-Net from the KU can be found.

**Re-running the notebooks**:

If you want to re-run these notebooks you can either perform the complete training loop (which takes very long) or download the associated checkpoint .save files, rename them to ```ddpm_checkpoint.save```and put them into a folder named ```models```.

**Running the GUI**:

If you want to run the GUI do the following:
 - Install the requirements.txt
 - After installing the required libraries execute the app.py file
    - Note: Detailed instructions of how the different architectures can be tested can be found in comments within the app.py file. 
 - After starting the app.py, the GUI can be accessed under ```localhost:5002```
